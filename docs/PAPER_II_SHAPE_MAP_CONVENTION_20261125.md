# 第二論文（三軸）の形の地図の取り方（Judge 承認、2026-11-25）

作成：Claude（通常監査）。宛先：Dig（ChatGPT）。第二論文の計算、記録、図は、この取り方にそろえる。

## 1. 取り方

- 半軸を (x, y, z) とし、**x = 1 を中間の軸**に固定する。**y ≤ 1 ≤ z**（y が短い軸、z が長い軸）。
- 角度エネルギーは楕円体の拡大・縮小で変わらない（角度は不変、重み (x−p)·n dA/(3Vol) は全体で 1 の割合）。したがって x = 1 の固定は、体積をそろえることと同じ形を表す。停留点の数、型、指数は同じで、位置が一律に伸び縮みするだけである。
- 軸の入れ替えは回転にすぎないので、y ≤ 1 ≤ z で、すべての形をちょうど一度ずつ数える。

## 2. 第一論文との対応

| 辺 | 形 | 第一論文の λ | 辺の上の閾値 |
|---|---|---|---|
| z = 1 | 扁平の回転楕円体（x = z） | λ = y | c_o ≈ 0.408、b_o ≈ 0.644 |
| y = 1 | 扁長の回転楕円体（x = y） | λ = z | b_p ≈ 2.065、c_p ≈ 4.724 |

- 球は角 (y, z) = (1, 1)。y → 0 が円盤の側、z → ∞ が針の側。
- 停留点の位置を第一論文と比べるときは、(y z)^(1/3) で割って体積をそろえる。閾値の比はそのまま比べられる。

## 3. 11 月 20 日の地図（V56）からの読み替え

- V56 は L = diag(1, s, st)（a₁ = 1 が短い軸、a₂ = s が中間、a₃ = st が長い軸）。全体を 1/s 倍すると **y = 1/s、x = 1、z = t** になる。
- **軸の名前が入れ替わる。** V56 の e₁（短い軸）は新しい y 軸、V56 の e₂（中間の軸）は新しい x 軸、e₃ は z 軸のまま。停留点の座標を移すときは、この入れ替えを必ず行い、記録に書く。
- 対の呼び方：V56 の「e₁ の対」＝**短軸の対**（指数 1）、「e₂ の対」＝**中間軸の対**（指数 2）。
- 曲線 Z₁、Z₂（中心の固有値の零）、∂₁、∂₂（極点トレースの零）の名前は V56 のまま使う。
