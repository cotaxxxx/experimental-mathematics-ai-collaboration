## 3. 書き足すとよい箇所（結論は変わらない）

1. **境界での極限：** e′(1⁻) を (4.4) の極限として求めるとき、積分と極限を入れ替えてよい理由を書く。
   - Δ ≥ 2r(1 − cosψ) から sin²ψ/Δ ≤ (1 + cosψ)/(2r) ≤ 1/r。また θ ≤ π/2 で、残りの因子も有界である。
   - したがって、r ∈ [1/2, 1) で被積分関数は一様に有界で、優収束定理が使える。
   - あわせて、この極限が定義 2.1 の勾配のトレース g∂ と一致することを一言添える。
2. **(4.5) が偶数次だけである理由：** θ(−r, ψ) = −θ(r, π − ψ) から e(−r) = e(r) となり、奇数次の項は 0 になる。このことを一行書く。Hessian の値には影響しない。
