## 11．工程の基本手順

REDDS最高正典に従い、研究工程を次の順序で管理する。

**研究計画 → 通常監査 → 条件固定 → Judgeの実行許可 → 計算 → 原本登録 → 独立照合 → Judge裁定**

| 段階 | 確認事項 |
|---|---|
| 計画 | 目的・対象範囲・定義・実行条件 |
| 監査 | 数学的妥当性・計算場所・資源 |
| 固定 | 入力・コード・SHA-256・実行条件 |
| 許可 | Judgeの承認 |
| 実行 | ログ・計算結果・停止条件 |
| 原本登録 | GitHub・証拠manifest |
| 独立照合 | 検証方法・独立性・一致範囲 |
| 裁定 | 成果の採否と研究の進退を別々に判断 |

## 12．証拠等級

| 区分 | 意味 |
|---|---|
| DIAGNOSTIC_ONLY | 診断・探索用 |
| NOT_EVIDENCE | 証明の証拠としては未採用 |
| PASS | 指定した試験条件に合格 |
| CLOSED | Judgeが指定範囲について完了と認めた状態 |
| OPEN | 必要な条件が未完了 |
| CANCELLED | Judgeによる研究中止 |

PASSやCLOSEDは、記録された対象範囲についてのみ有効である。

数学的成果の採否と、研究を継続するかどうかの判断は独立して記録する。
