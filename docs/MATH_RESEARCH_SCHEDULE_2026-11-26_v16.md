### 提案権

**通常の提案担当はClaudeとする。**

その他の参加AIは、特別に必要な場合に限り、理由、目的、対象範囲、費用・実行負荷への影響を明示して提案できる。

提案権と承認権は別である。

特別Dig、特別監査、Fable 5.2による査読などの使用はJudgeが承認する。

### 計算の実行場所

通常の計算は、短い確認を除き、Digが研究PCで実行する。

AIの作業環境では長時間の計算を実行しない。

特別監査の独立再計算については、実行場所、担当、資源条件をJudgeが案件ごとに決める。

Judgeの明示的な許可なく、新たな監査再計算を開始しない。

## 11．工程の基本手順

REDDS最高正典に従い、研究工程を次の順序で管理する。

**研究計画 → 通常監査 → 条件固定 → Judgeの実行許可 → 計算 → 原本登録 → 独立照合 → Judge裁定**

| 段階 | 確認事項 |
|---|---|
| 計画 | 目的・対象範囲・定義・実行条件 |
| 監査 | 数学的妥当性・計算場所・資源 |
| 固定 | 入力・コード・SHA-256・実行条件 |
| 許可 | Judgeの承認 |
| 実行 | ログ・計算結果・停止条件 |
| 原本登録 | GitHub・証拠manifest |
| 独立照合 | 検証方法・独立性・一致範囲 |
| 裁定 | 成果の採否と研究の進退を別々に判断 |

---

## 12．証拠等級

| 区分 | 意味 |
|---|---|
| DIAGNOSTIC_ONLY | 診断・探索用 |
| NOT_EVIDENCE | 証明の証拠としては未採用 |
| PASS | 指定した試験条件に合格 |
| CLOSED | Judgeが指定範囲について完了と認めた状態 |
| OPEN | 必要な条件が未完了 |
| CANCELLED | Judgeによる研究中止 |

PASSやCLOSEDは、記録された対象範囲についてのみ有効である。

数学的成果の採否と、研究を継続するかどうかの判断は独立して記録する。

---

## 13．研究中止時の手順

Judgeが研究中止を裁定した場合は、新規投入と自動再開を停止する。

実行中の計算について停止を確認し、完了した結果と未判定事項を記録する。

既存の証拠、コード、計算記録、公開成果は原則として保全する。

再開はJudgeの新たな裁定を必要とする。

三軸研究については、2026年11月22日の中止裁定を歴史的な記録として保持する。**2026年11月23日のJudgeの新裁定により研究全体の中止状態は解除された**。撤回済みの旧E2指示は復活しないが、別途Judgeが承認したE2 v2.1実行指示と独立検算依頼は有効。その他の旧計算・開発は自動再開しない。
